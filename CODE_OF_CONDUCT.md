# Community conduct

WRECKLANDS welcomes contributors with different levels of programming, game-design, and tabletop experience.

Project spaces should remain constructive and task-focused. Contributors are expected to:

- discuss ideas and code without personal attacks;
- give actionable, specific feedback;
- respect boundaries and privacy;
- avoid harassment, threats, discriminatory abuse, or deliberate disruption;
- credit other contributors and sources appropriately;
- keep rules and IP discussions grounded in documented project requirements.

Maintainers may edit or remove abusive content, close disruptive threads, or restrict participation when necessary to protect the project community.

If a conduct problem involves a security or privacy concern, use the private reporting guidance in `SECURITY.md` rather than posting sensitive details publicly.
