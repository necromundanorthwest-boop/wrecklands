# Security policy

## Reporting a vulnerability

Please do not publish credentials, exploit details, private room data, or a working attack in a public issue.

If GitHub's **Report a vulnerability** / private security-advisory feature is available for this repository, use it. Otherwise, contact a repository maintainer privately through an appropriate GitHub channel before disclosing technical details publicly.

Useful reports include:

- affected version/commit;
- reproduction steps;
- expected and observed behavior;
- whether the issue crosses room or player boundaries;
- whether duplicate-action, authentication, persistence, or state-authority guarantees are affected.

## Supported version

Security fixes currently target the latest version on `main` and the current public deployment, when one exists.
